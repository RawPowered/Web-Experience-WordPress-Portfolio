# Evidence, ownership and limits

This specialty portfolio indexes existing public work. It does not replace the originating project repositories.

| Evidence type | Meaning |
|---|---|
| Public capture / report | Direct dated observation in the linked case; scope and source window remain attached. |
| Public source or tour | Implementation/docs support review; fictional data, private deployment, or pending acceptance are disclosed. |
| Historical experience | Work and surviving history are bounded by the contemporaneous evidence. |
| Proposal | A roadmap or design checklist, not a completed result. |

## Primary sources

- [305UGC — current website & mobile journey](https://github.com/RawPowered/305UGC-Showcase) — Live public site; paired 1440px and 390px homepage captures; guided quote path; WordPress–Zoho architecture.
- [RoofRoofTexas — full rebuild](https://github.com/RawPowered/RoofRoofTexas-Rebuild) — Before/after architecture, conversion flow, responsive navigation, media pipeline, security hardening and local SEO.
- [PowerPortals — WordPress portal product](https://github.com/RawPowered/PowerPortals-Showcase) — Fictional-data tour for modular intake, team portals and Zoho CRM companion widgets.
- [Zoho CRM widgets — product extension UX](https://github.com/RawPowered/Zoho-CRM-Widgets) — Fictional tours of CRM workspaces and embedded operational widgets.

This repository reuses only existing public images, screenshots and aggregate statistics. Private client source, customer records, CRM URLs, personal identifiers and credentials are excluded. The relevant source and status links appear beside each case.

UI and capture evidence belongs to the cited live site or fictional-data product tour. Plugin source and commercial deployment assets remain private. A rendered tour does not claim a client installation has completed acceptance.
